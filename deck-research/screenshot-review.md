# Screenshot and Recording Review Guide

## Use the right visuals for the LLM-first story

The current deck should not lead with raw agent names, internal requirement IDs, hashes, or a dense rule matrix. The audience should first understand the human consequence and then see that the AI is genuinely doing bounded investigative work.

| Required capture | Why it matters | Framing guidance |
|---|---|---|
| **AI/MCP ready state** | Establishes that the default browser path uses the LLM, rather than a hidden deterministic replay. | Keep the top status and Maeve card visible; crop away navigation chrome. |
| **Readable MCP trace** | Demonstrates model-driven tool discovery and sequencing. | Show tool labels in plain language; avoid raw request payloads. |
| **41% → 38% source comparison** | Makes the regulatory change concrete before discussing architecture. | Use a tight Before / Now crop with the effective-date explanation. |
| **Old-rate return** | Proves that a plausible, coherent answer can be safely rejected. | Highlight the plain-language “Needs correction” outcome. |
| **Current-rate acceptance** | Proves the controlled recovery path and closing result. | Use a matching frame beside the old-rate return. |
| **Proof record** | Shows that the source-to-action route remains inspectable. | Label it “proof record”; do not call it regulator-approved or immutable legal evidence. |

## Do not reuse the pre-LLM screenshots as primary evidence

Earlier captures of source statistics, internal codes, or raw agent traces are useful only for technical backup. They do not show the new visible MCP orchestration. Recapture the six frames above from the current deployment before final submission.

## Visual QA before using a capture

- [ ] The top status says **AI / MCP READY**, or the fallback state is explicitly labelled.
- [ ] No browser automation overlays, devtools panes, or unrelated tabs are visible.
- [ ] No secrets, API keys, personal data, or ambiguous factual claims appear.
- [ ] Text is legible at slide size; do not use a full-page browser screenshot with 10-point text.
- [ ] The old-rate and current-rate frames use the same zoom, viewport, and context.
- [ ] Any count on the slide matches the current public release: 115 tests, 12 MCP tools, nine rule packs, eight acceptance checks.
- [ ] The capture describes a prepared synthetic case and controlled source snapshots.
